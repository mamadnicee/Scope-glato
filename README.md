# اسکوپ — Scoop Gelato 🍦

لندینگ سه‌بعدی بستنی با الهام از تمپلیت Soda (سبک 21st.dev)
ساخته‌شده با React + Vite + Three.js + GSAP + Tailwind CSS

## ویژگی‌ها

- بستنی سه‌بعدی (قیف وافلی، دو اسکوپ، قطره‌های آب‌شده، ویفر، ترافل) که به سمت ماوس می‌چرخد
- میوه‌ها و تاپینگ‌های سه‌بعدی شناور با پارالاکس و «میدان نیرو» (با نزدیک شدن ماوس فرار می‌کنند)
- ۳ طعم: توت‌فرنگی، بلوبری، پسته — با کلیک روی کارت‌ها:
  - رنگ پس‌زمینه و رنگ تأکیدی کل سایت عوض می‌شود
  - بستنی ۷۲۰ درجه با موشن‌بلور می‌چرخد و طعمش عوض می‌شود
  - تاپینگ‌ها به مرکز جمع می‌شوند، عوض می‌شوند و دوباره منفجر می‌شوند
- ریزش ترافل‌های رنگی و دانه‌های برف
- کلیدهای ← و → کیبورد برای تغییر طعم
- فونت فارسی Lalezar و Vazirmatn، همراه با فونت انگلیسی Galada
- واکنش‌گرا برای موبایل

## بدون هیچ فایل تصویری

تمام مدل‌ها، تصاویر کارت‌ها و بافت قیف **داخل کد ساخته می‌شوند** (Three.js).
هیچ فایل `.glb` یا `.png` لازم نیست، پس چیزی موقع دانلود یا دیپلوی گم نمی‌شود.

## اجرا روی کامپیوتر

پیش‌نیاز: Node.js نسخه 20 یا بالاتر

```bash
npm install
npm run dev
```

## بیلد

```bash
npm run build
```

خروجی: `dist/index.html` — **فقط یک فایل HTML** که همه چیز داخلش است.
(برای تست سریع می‌توانید همین یک فایل را مستقیم در مرورگر باز کنید.)

## دیپلوی روی Cloudflare Pages

1. پروژه را روی GitHub بفرستید:
   ```bash
   git init
   git add .
   git commit -m "scoop gelato"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
2. در Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**
3. تنظیمات:
   - Framework preset: `Vite`
   - Build command: `npm run build`
   - Build output directory: `dist`
4. متغیر محیطی: `NODE_VERSION` = `20`
5. **Save and Deploy**

## ساختار پروژه

```
src/
  App.tsx                 ← چیدمان صفحه (هدر، تیترها، کارت‌ها)
  index.css               ← تمام استایل‌ها و نسخه‌ی موبایل
  components/Sprinkles.tsx← ترافل‌ها و برف‌های در حال ریزش
  three/
    flavors.ts            ← ⭐ طعم‌ها، رنگ‌ها، قیمت‌ها (برای ویرایش محتوا)
    engine.ts             ← موتور انیمیشن (چرخش، پارالاکس، میدان نیرو، تعویض طعم)
    iceCream.ts           ← مدل سه‌بعدی بستنی
    toppings.ts           ← گیلاس، توت‌فرنگی، بلوبری، شکلات، پسته، برگ نعناع
    textures.ts           ← بافت وافل و نویز
public/_redirects         ← جلوگیری از خطای ۴۰۴ در Cloudflare
```

## افزودن طعم جدید

در `src/three/flavors.ts` یک آبجکت جدید به آرایه‌ی `FLAVORS` اضافه کنید
(رنگ پس‌زمینه، رنگ اسکوپ‌ها، تاپینگ‌ها). کارت و انیمیشن آن خودکار ساخته می‌شود.
