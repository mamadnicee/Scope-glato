# اسکوپ — Scoop Gelato 🍦

لندینگ سه‌بعدی بستنی (الهام‌گرفته از تمپلیت Soda / سبک 21st.dev). **مدل‌های سه‌بعدی با کد ساخته شده‌اند؛ تصاویر کارت‌ها نیز رندر واقعی همین مدل‌ها هستند و در `public/images/` همراه سورس نگهداری می‌شوند.**

React + Vite + Three.js + GSAP + Tailwind CSS

## امکانات

**هیرو (تمام‌صفحه، همان سبک Soda)**
- بستنی سه‌بعدی (قیف وافلی، دو اسکوپ، قطره‌های آب‌شده، ویفر، ترافل و تاپر) که به سمت ماوس می‌چرخد
- میوه‌ها و تاپینگ‌های شناور با پارالاکس + «میدان نیرو» (تا ۴۰۰ پیکسلی از ماوس فرار می‌کنند)
- کلمه‌ی بزرگ انگلیسی پشت بستنی که با هر طعم عوض می‌شود
- ریزش ترافل و دانه‌های برف
- تغییر طعم با فلش‌ها، کارت‌ها یا کلیدهای ← و →

**تعویض طعم (کورئوگرافی کامل)**
۱. بستنی ۳۶۰ درجه با موشن‌بلور می‌چرخد → ۲. در اوج چرخش طعم عوض می‌شود → ۳. تا ۷۲۰ درجه ادامه می‌دهد
- همزمان: پس‌زمینه و رنگ تأکیدی کل سایت عوض می‌شود، تاپینگ‌ها به مرکز جمع می‌شوند، مدلشان عوض می‌شود و دوباره منفجر می‌شوند

**۹ طعم:** توت‌فرنگی، بلوبری، پسته، شکلات تلخ، زعفران‌وزرشک، آلبالو، نارگیل، کیوی، خرما‌وگردو

**صفحه‌ی کامل با اسکرول**
| بخش | توضیح |
|---|---|
| `#hero` | بستنی سه‌بعدی تعاملی |
| `#flavors` | گرید ۹ طعم + دکمه «نمایش سه‌بعدی» و «سفارش» |
| `#ingredients` | ۸ ماده‌ی اولیه با عکس سه‌بعدی |
| `#process` | ۴ مرحله‌ی تولید + شمارنده‌های متحرک |
| `#reviews` | اسلایدر نظرات با ستاره |
| `#order` | فرم سفارش با انتخاب طعم و محاسبه‌ی قیمت |

**صدا (Web Audio، بدون فایل صوتی)**
- دکمه‌ی بلندگو در هدر: کلیک، «اسکوپ گرفتن» هنگام تعویض طعم، جینگل ظاهر شدن طعم، و هوم ملایم محیطی

## بهینه‌سازی‌ها
- رندر سه‌بعدی فقط وقتی هیرو در دید است کار می‌کند (IntersectionObserver) → هنگام اسکرول CPU آزاد می‌شود
- سه بوم (لایه‌ی عقب/هیرو/جلو) با DPR محدود روی موبایل
- مدل سه‌بعدی زنده در مرکز هیرو اجرا می‌شود؛ تصویر ۹ طعم و ۸ ماده‌ی اولیه از فایل‌های محلی بارگذاری می‌شود تا فشار WebGL اضافی روی گوشی نباشد.
- **خروجی `dist/index.html` یک فایل کاملاً مستقل است:** هر ۱۷ تصویر به‌صورت base64 داخل خود HTML درج می‌شود؛ حتی اگر در دیپلوی فقط فایل HTML آپلود شود (بدون پوشه `images`)، هیچ تصویری ۴۰۴ نمی‌شود و گوی‌های جایگزین ظاهر نمی‌شوند.
- کپی‌های قابل مشاهدهٔ تصاویر در `public/images/` (برای مرور و ZIP) و نسخهٔ فعال برای بیلد در `src/assets/images/` نگهداری می‌شود.
- در موبایل بستنی و میوه‌های معلق داخل ناحیه‌ی مستقل بین دکمه و کارت‌ها قرار می‌گیرند؛ هیرو در صفحه‌های کوتاه به جای بریدن محتوا بلندتر می‌شود.

## اجرا

پیش‌نیاز: Node.js نسخه ۲۰ یا بالاتر

```bash
npm install
npm run dev      # اجرای محلی
npm run build    # خروجی: dist/index.html (تک‌فایل)
```

برای تست چیدمان و تمام ۹ تعویض طعم در موبایل و دسکتاپ:

```bash
npx playwright install chromium
npm run check:layout
```

## دیپلوی روی Cloudflare Pages

```bash
git init
git add .
git commit -m "scoop gelato"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

سپس در Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**
- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Environment variable: `NODE_VERSION` = `20`

فایل `public/_redirects` هم هست تا صفحه‌ی ۴۰۴ نگیرید.

## ساختار پروژه

```
src/
  App.tsx                  ← چیدمان صفحه، هیرو، هدر، کلید صدا
  index.css                ← همه‌ی استایل‌ها + نسخه‌ی موبایل
  components/
    Sprinkles.tsx          ← ترافل و برف در حال ریزش
    Sections.tsx           ← بخش‌های اسکرولی (طعم‌ها، مواد، کارگاه، نظرات، سفارش، فوتر)
  three/
    flavors.ts             ← ⭐ طعم‌ها، رنگ‌ها، قیمت‌ها (برای تغییر محتوا اینجا را ویرایش کنید)
    engine.ts              ← موتور: چرخش، پارالاکس، میدان نیرو، تعویض طعم، ساخت عکس‌ها
    iceCream.ts            ← مدل سه‌بعدی بستنی
    toppings.ts            ← ۸ تاپینگ سه‌بعدی
    textures.ts            ← بافت وافل + نویز
  utils/
    soundManager.ts        ← صداهای سایت با Web Audio
scripts/export-model-images.mjs  ← خروجی گرفتن تصاویر کارت‌ها از مدل‌های Three.js
src/assets/images/               ← ۱۷ عکس PNG شفاف (نسخه‌ای که در بیلد درون‌خطی می‌شود)
public/images/                   ← کپی قابل مشاهدهٔ همان ۱۷ عکس (۹ طعم + ۸ ماده)
public/_redirects
```

## افزودن طعم جدید

در `src/three/flavors.ts` یک آبجکت به `FLAVORS` اضافه کنید:

```ts
{
  id: 'mango', fa: 'انبه', en: 'Mango', giant: 'MANGO',
  price: '۱۰۲ هزار تومان', priceValue: 102000, kcal: 175,
  note: 'انبه‌ی رسیده + کمی آبلیمو', base: 'شیر تازه',
  bg: { inner: '#f0a52a', mid: '#8a4d08', outer: '#231202' },
  accent: '#fff2c9', ink: '#2b1602',
  scoops: ['#ffb648', '#ffe0a3'],
  toppings: ['cherry', 'mint'],   // تاپینگ‌های شناور
  topper: 'cherry',               // تاپر روی بستنی: cherry | blueberry | pistachio | chocolate | kiwi | date
  decor: 'sprinkles',             // sprinkles یا nuts
  tag: 'فصلی',                    // اختیاری
}
```

کارت، رنگ سایت، انیمیشن تعویض و فرم سفارش خودکار ساخته می‌شوند. برای ذخیره تصویر محصول جدید در `public/images/`:

```bash
npx playwright install chromium
npm run assets
```

این دستور مدل‌ها را رندر می‌کند و فایل‌های PNG خود پروژه را جایگزین می‌کند. اسکریپت تنها برای ساخت عکس‌هاست و اجرای سایت یا دیپلوی به Chromium نیاز ندارد.
